# 🕵️‍♂️ Tradução do Jogo - Database Detective (PT-BR)

Este repositório contém os arquivos de tradução para o português do Brasil (PT-BR) do jogo **Database Detective** na Steam. O objetivo deste projeto é tornar o jogo mais acessível para a comunidade brasileira, traduzindo toda a interface, menus e linhas de texto do banco de dados.

---

## 📂 Estrutura do Repositório

* **`Traducoes_PT-BR/`**: Pasta que armazena os arquivos de modificação textuais traduzidos.
* **`README.md`**: Instruções de instalação e documentação do projeto.

---

## 🚀 Como Instalar a Tradução

Siga os passos abaixo para aplicar a tradução ao seu jogo na Steam:

1. **Baixe os arquivos:**
   * Clique no botão verde **Code** (no topo desta página) e selecione **Download ZIP**.
   * Extraia os arquivos em uma pasta de sua preferência.

2. **Encontre a pasta do jogo na Steam:**
   * Abra a sua biblioteca Steam.
   * Clique com o botão direito sobre o **Database Detective**.
   * Vá em **Gerenciar** > **Explorar arquivos locais**.
   * *Opcional (Caminho padrão):* `C:\Program Files (x86)\Steam\steamapps\common\Database Detective`

3. **Substitua os arquivos:**
   * Copie o conteúdo de dentro da pasta `Traducoes_PT-BR` que você baixou.
   * Cole dentro da pasta correspondente do jogo que se abriu no passo anterior.
   * Substitua os arquivos originais quando o sistema solicitar.

4. **Jogue:**
   * Inicie o jogo normalmente pela Steam.
